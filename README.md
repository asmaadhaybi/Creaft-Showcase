# Creaft – Handmade Marketplace

## 📱 About Creaft

Creaft is a mobile marketplace application designed to connect customers with vendors offering handmade and creative products.

The application provides customers with a simple shopping experience while allowing vendors to manage their products and marketplace activities.

## ✨ Main Features

- User registration and authentication
- Customer and vendor accounts
- Product browsing and categories
- Product management
- Shopping and ordering
- Role-based access
- User profile management
- Administrative management
- REST API integration

## 👥 User Roles

### 👤 Customer
Customers can browse products, explore categories, and shop through the application.

### 🏪 Vendor
Vendors can add and manage their products and manage their marketplace activities.

### 🛡️ Super Admin
The super admin can manage and monitor the overall platform.

## 🛠️ Technologies

- Hostinger

## 🏗️ Architecture

Creaft follows a client-server architecture:

React Native Mobile Application  
↓  
Laravel REST API  
↓  
MySQL Database

The mobile application communicates with the Laravel backend through REST APIs for authentication, users, products, orders, and other application functionality.
